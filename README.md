# 🧮 Calculator

A simple and responsive Calculator web application built using **HTML, CSS, and JavaScript**.

This project is created to practice JavaScript fundamentals, DOM manipulation, event handling, and basic mathematical operations.

 🚀 Features

- Addition, subtraction, multiplication, and division
- Clear button to reset the calculation
- Interactive calculator buttons
- Real-time display of entered values
- Simple and clean user interface
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
